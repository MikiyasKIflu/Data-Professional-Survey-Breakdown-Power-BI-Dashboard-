# 📊 Data Professional Survey Breakdown (Power BI Dashboard)

## 📋 Project Overview
This interactive Power BI dashboard analyzes survey responses from data professionals worldwide. It explores key demographic trends, salary distributions across job titles, programming language preferences, work-life balance satisfaction, and industry entry barriers.

## 🔍 Key Insights & Visualizations
* **Country Distribution:** Highlights where the highest concentration of survey participants are located using a treemap view.
* **Salary Breakdown:** Compares average salaries across various roles (Data Scientist, Data Engineer, Data Analyst, etc.).
* **Programming Languages:** Stacked visual showing preferred programming languages mapped by role.
* **Satisfaction Metrics:** Gauge charts visualizing average employee satisfaction with work/life balance and salary.
* **Entry Barriers:** Donut chart analyzing how difficult respondents found it to break into the data field.

---

## 🛠️ Tools & Skills Demonstrated
* **Tool:** Power BI Desktop, Power Query
* **Data Transformation:** Column profiling, conditional columns, type casting, and data cleaning.
* **Data Modeling:** Managing relationships and filtering contexts.
* **Data Visualization:** Using custom color themes, gauge charts, treemaps, and clustered bar charts for executive-level storytelling.
